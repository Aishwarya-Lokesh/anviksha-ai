# ANVIKSHA AI — Phase 1 Frontend Prototype

## Run locally

```bash
npm install
npm run dev
```

Then open http://localhost:3000 — pick Student, Teacher, or Admin from the landing page.

## What's included
- Full Student, Teacher, and Admin dashboards (Next.js 14 App Router)
- All mock data lives in /data/*.json — edit these to change what's shown
- Tailwind + Framer Motion + Recharts, design system in /components/ui

## Notes
- This is Phase 1: frontend only, no backend/auth/real AI — everything runs on local mock data
- Google Fonts (Inter/Sora) load from the internet at runtime; if you're offline the UI falls back to system fonts automatically
